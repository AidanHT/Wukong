# `data/gpt2/` — GPT-2 124M export

Binary fixtures for the GPT-2 example programs (`examples/gpt2_infer.wk`,
`examples/gpt2_forward_bench.wk`, `examples/gpt2_forward_bench_par.wk`, and related files).
Programs read these paths relative to the repo root when run with `wukongc --run` from the
checkout root.

## What is in git

Only [`MANIFEST.md`](MANIFEST.md) is tracked — it documents tensor layout, element offsets, and
the frozen test prompt (`Hello, my name is` → argmax 1757, `" John"`). The weight and reference
blobs are **not** in git (~475 MB total); `/data/` is gitignored.

## Expected files (after export)

Generated by [`tools/export_gpt2.py`](../../tools/export_gpt2.py) (requires PyTorch + HuggingFace
`gpt2`):

| File | Role |
|------|------|
| `gpt2_124m_weights.bin` | Flat little-endian f32 weights (~497 MB) |
| `gpt2_tokens.bin` | Prompt token ids (`i32`, length 5) |
| `gpt2_ref_logits.bin` | Authoritative HF reference logits for verification |

Programs may also write outputs here (for example `gpt2_wuk_logits.bin` or
`gpt2_bench_lastrow.bin`) during a run; those are local scratch, not part of the export.

## Regenerating

From the repo root, with dependencies installed:

```sh
python tools/export_gpt2.py
```

Output directory resolution (same as `tools/verify_gpt2.py`): `$GPT2_DATA_DIR`, then an optional
`argv[1]` path, then `<repo>/data/gpt2` by default. The exporter also refreshes
`examples/gpt2_config.wk` and rewrites `MANIFEST.md`. A successful run prints
`EXPORTER SELF-CHECK PASS argmax=1757 maxdiff=...`.

Cross-check logits after inference with `python tools/verify_gpt2.py`.
